# AfrlvScaner

Приложение для macOS, которое сканирует несколько объектов со стекла планшетного сканера за один проход и раскладывает их по отдельным страницам. Подходит для фотографий, чеков, открыток и обложек.

Всё в одном окне и без диалогов: превью, выбор областей, скан, сохранение.

## Возможности

- **Превью всего стекла** в оттенках серого. Сразу после превью приложение само находит объекты (Vision плюс запасной алгоритм) и ставит рамки.
- **Области в миллиметрах.** Их можно нарисовать вручную, передвинуть, изменить размер, удалить. Одновременно поддерживается несколько областей. Если рамки уже поправлены руками, повторное превью их не трогает.
- **Финальный скан одним проходом** по объединению областей, нарезка на страницы делается на Mac.
- **Режимы:** цвет, серый, ч/б. Разрешение — из списка, который поддерживает сканер.
- **Лента страниц:** поворот, удаление, перестановка перетаскиванием.
- **Сохранение без диалогов** в `~/Documents/Scans` с именем вида `scan_2026-10-25_110500`:
  - PDF одним файлом или отдельный PDF на каждую область;
  - JPEG.

  PDF проверяется после записи. Ч/б страницы сохраняются без JPEG-сжатия. Папку для сохранения можно поменять в настройках (⌘,).
- **Состояние сканера** видно по точке на кнопке сканера: зелёная — готов, оранжевая — занят, красная — ошибка, серая — сканер не найден.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| ⌘P | Превью |
| ⌘A | Найти объекты автоматически |
| ⌘↩ | Сканировать |
| ⌘S | Сохранить |
| ⌫ | Удалить выбранную область или страницу |
| R | Повернуть выбранную страницу (когда фокус в ленте) |
| Esc | Снять выделение области |
| ⌘, | Настройки |

## Требования

- macOS 14 Sonoma или новее.
- Сканер, который виден системе через ImageCaptureCore: AirScan/eSCL по сети или USB со штатным драйвером. Если сканер открывается в «Захвате изображений», он подойдёт.

Проверено на **Deli M1820W** (AirScan, сеть). Samsung SCX-3200 работает только после установки драйвера с поддержкой ICA.

## Установка

1. Скачайте `AfrlvScaner-x.y.z.dmg` со страницы [Releases](https://github.com/afrlv/my-scaner-app-macos/releases).
2. Откройте образ и перетащите AfrlvScaner в «Программы».
3. Приложение подписано ad-hoc, без нотаризации. Поэтому при первом запуске macOS может его не открыть:
   - в Finder щёлкните по приложению правой кнопкой → «Открыть»;
   - или разрешите запуск в «Системные настройки» → «Конфиденциальность и безопасность».
4. Когда приложение попросит доступ к локальной сети, разрешите его: без этого оно не найдёт сетевые сканеры.

> Пока открыт «Захват изображений» или другая программа сканирования, она держит сессию сканера. Закройте её перед работой с AfrlvScaner.

## Сборка из исходников

Нужны Xcode 16+ (Swift 6) и [XcodeGen](https://github.com/yonaskolb/XcodeGen). Проект Xcode генерируется из `project.yml`, в репозитории его нет.

```sh
brew install xcodegen
xcodegen generate
open AfrlvScaner.xcodeproj
```

Release-сборка из командной строки:

```sh
xcodebuild -scheme AfrlvScaner -configuration Release \
  -destination 'platform=macOS' -derivedDataPath build/dd-release build
open build/dd-release/Build/Products/Release/AfrlvScaner.app
```

Иконку генерирует скрипт `swift scripts/make_icon.swift`.

### Демо-режим без сканера

```sh
open -n --env AFRLV_MOCK=1 build/dd-release/Build/Products/Release/AfrlvScaner.app
```

С `AFRLV_MOCK=1` вместо настоящего сканера подключается встроенный демо-сканер с тестовой картинкой.

## Тесты

```sh
xcodebuild test -scheme AfrlvScaner -destination 'platform=macOS'
```

Обычные тесты всегда работают с демо-сканером и реальный сканер не занимают.

Живые тесты на подключённом сканере по умолчанию пропускаются. Запускайте их по одному, не параллельно:

```sh
# проверка сервиса на реальном сканере
TEST_RUNNER_AFRLV_LIVE_SCANNER=1 xcodebuild test -scheme AfrlvScaner -destination 'platform=macOS' \
  -only-testing:AfrlvScanerTests/ScannerServiceLiveTests

# замер скорости превью и скана
TEST_RUNNER_AFRLV_BENCH=1 xcodebuild test -scheme AfrlvScaner -destination 'platform=macOS' \
  -only-testing:AfrlvScanerTests/PreviewBenchmarkLiveTests
```

## Структура

```
AfrlvScaner/
  App/        точка входа
  Model/      типы: режимы, области, страницы, возможности сканера
  Core/       геометрия мм ↔ пиксели, обработка изображений, поиск областей, экспорт, настройки
  Scanner/    работа со сканером через ImageCaptureCore, сборка полос, демо-сканер
  State/      состояние приложения
  UI/         SwiftUI-интерфейс
AfrlvScanerTests/  модульные и живые тесты
docs/mockup.html   эскиз интерфейса
scripts/           генерация иконки
```
