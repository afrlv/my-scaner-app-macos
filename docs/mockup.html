Один экран

  • Нет диалогов и вспомогательных окон. Настройки скана умещаются в тулбаре в одну строку.
  • Сохранение работает без диалога: файл ложится в папку по умолчанию с автоименем, путь показан в статусной строке.
  • Папка меняется в стандартном меню «Настройки» (⌘,), это единственное исключение.

Быстродействие

  • Сессия со сканером открывается при запуске и не закрывается. Превью стартует без повторного подключения.
  • Если областей несколько, сканер делает один проход по их общему габариту, а области вырезаются уже на Mac.
  • Превью рисуется по полосам по мере прихода данных. Автопоиск областей на 75 dpi занимает около 50 мс.
  • После смены сканера или режима старое превью тускнеет, но остаётся на экране, и рамки можно править сразу.

Минимум элементов

  • Тулбар: сканер, режим, DPI и три действия. У каждого есть горячая клавиша.
  • Если областей нет, сканируется всё стекло. Для одной или нескольких областей отдельных режимов нет.
  • Справа сводка, которая только показывает данные: размеры областей в мм, итоговый размер в пикселях и время скана.
